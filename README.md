# 心臟病（Heart Attack）

翻牌看到「心臟病號碼」就**馬上拍下去**！最慢拍到的人要把整疊牌收走。心臟病是台灣童玩中經典的反應力遊戲，這裡是你對決 AI 的單人版本。

## 玩法

1. 選一個心臟病號碼（A～K，也可直接開局隨機）。
2. 按「開始翻牌」，你與阿強輪流翻牌。
3. 翻開的牌等於心臟病號碼時，畫面會跳出「快拍！」— 用最快的速度按下「拍！」。
4. 反應最慢的人把牌堆整疊收走（牌越多越危險）。
5. 手牌清空就出局，**最後留在場上的人獲勝**。

> 高手祕技：連贏三回合以上阿強會開始變快；一直被阿強電，他也會稍微大意。

## 操作

- 滑鼠／觸控：按「拍！」。
- 鍵盤：`空白鍵` 即時反應。
- 點頂上的號碼可在開局前指定心臟病數字。

## 技術

- `game.js`：純函式邏輯（發牌、翻牌、拍點判定、出局與勝負）— 可單元測試。
- `app.js`：Svelte 免框架的 DOM 渲染與 AI 節奏（動態 AI 反應時間）。
- `audio.js`：Web Audio 合成音效，無需音檔。
- 最佳處理方式：連勝次數存 `localStorage`，並嘗試同步至 Playgrounds `/api/kv`。
